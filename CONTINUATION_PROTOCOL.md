# CONTINUATION PROTOCOL — WORLD BLOCKBUSTER

Новый чат не начинает писать роман автоматически.

Сначала прочитать:
1. PROJECT_STATE.md
2. MASTER_BLOCK_STATUS.md
3. MASTER_PROMPT.md
4. DECISION_LOG.md
5. CHARACTER_BIBLE.md
6. WORLD_BIBLE.md
7. WORLD_RULES.md
8. MYSTERY_LEDGER.md
9. ARCHITECTURE.md
10. SCENE_PLAN.md
11. CHAPTER_STATUS.md
12. последние главы, если они существуют.

Если файл ещё не создан, считать его незавершённым, а не придумывать его содержимое.

После чтения:
- проверить последний commit;
- проверить CHANGE_LOG.md;
- определить текущий блок;
- не менять утверждённые решения без записи в DECISION_LOG.md.

Производственный цикл главы:
CHAPTER BRIEF → DRAFT → LITERARY QA → CONTINUITY QA → MYSTERY QA → PARAGRAPH QA → WORD COUNT → GITHUB → VERIFY.

Без всех проверок глава не считается завершённой.
