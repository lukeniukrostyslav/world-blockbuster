# B0 — НОВЫЙ НУЛЕВОЙ СТАРТ WORLD BLOCKBUSTER

Дата: 22 сентября 2026.

## Решение

Предыдущая разработка WORLD BLOCKBUSTER полностью аннулирована как рабочая архитектура.

Не переносим автоматически ни одного прежнего:
- героя;
- имени;
- мира;
- города;
- существа;
- конфликта;
- тайны;
- персонажа;
- места;
- сюжета;
- плана глав;
- оценки;
- процентного прогресса.

## Исследовательская база

В проекте доступны пять загруженных книг:

1. Harry Potter and the Philosopher’s Stone — J.K. Rowling
2. The Hobbit — J.R.R. Tolkien
3. Percy Jackson and the Lightning Thief — Rick Riordan
4. Coraline — Neil Gaiman
5. The Graveyard Book — Neil Gaiman

Главный принцип: исследование ведётся постоянно, начиная с B0 и продолжаясь через все последующие блоки.

Особое внимание уделяется загруженному Harry Potter: не только общему сюжету, а фактической организации книги — персонажам, сценам, темпу раскрытия мира, социальным отношениям, семейной среде, повторяющимся фигурам, устройству приключения, юмору, тайне, правилам, эмоциональным ставкам и переходам между обычной и необычной жизнью.

Остальные четыре книги также изучаются как самостоятельные исследовательские источники.

## Запрет копирования

Мы не переносим:
- текст;
- имена;
- персонажей;
- миры;
- названия;
- конкретные сцены;
- уникальные сюжетные решения;
- узнаваемые конструкции конкретной франшизы;
- имитацию индивидуальной авторской манеры.

Из книг извлекаются только наблюдаемые общие механизмы повествования и читательского вовлечения, после чего создаётся новый IP.

## Производственный принцип

Не начинаем роман преждевременно.

Порядок:

B0 → исследование → формирование требований → концепция → герой → мир → персонажи → тайна → конфликт → архитектура → главы → рукопись → редактура → QA.

Каждый блок должен иметь доказуемый результат.

100% ставится только после фактического завершения блока и сохранения результата в GitHub.

## Контроль качества

Для каждого блока проверяется:

- что было исследовано;
- что создано;
- что ещё неизвестно;
- какие решения приняты;
- какие решения намеренно не приняты;
- какие ограничения действуют;
- какие связи с предыдущими блоками существуют;
- не появилось ли случайного копирования исследуемых произведений.

## Главный принцип

Мы не пытаемся «сделать новый Гарри Поттер».

Мы пытаемся понять, почему великие приключенческие книги работают, постоянно проверяя это по загруженным материалам, а затем создать полностью самостоятельный блокбастер.

## Статус

B0 — завершён как новый производственный старт.
Все последующие блоки должны быть созданы заново.
