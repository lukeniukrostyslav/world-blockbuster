# B19.7 — ДИАЛОГИ И ОТНОШЕНИЯ

Диалог не должен существовать только для передачи информации читателю.

Правила:
- каждый говорящий чего-то хочет;
- реплики отражают характер и отношения;
- люди не обязаны говорить всё прямо;
- между репликами присутствуют действия, взгляды, паузы и реакции там, где они нужны;
- юмор рождается из характера и ситуации;
- дружба строится через совместные действия, разговоры, помощь, ошибки и конфликты;
- соперничество существует не только во время главной загадки;
- отношения меняются постепенно и сохраняют память о предыдущих сценах.
