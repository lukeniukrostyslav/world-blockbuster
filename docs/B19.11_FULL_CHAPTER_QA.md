# B19.11 — ФИНАЛЬНЫЙ QA КАЖДОЙ ГЛАВЫ

Перед сохранением каждой главы проверять:

1. Герой появляется достаточно рано.
2. Читатель понимает место и ситуацию.
3. Персонажи введены постепенно.
4. Нет информационного дампа.
5. Нет искусственных строк по 2–4 слова.
6. Абзацы выглядят как нормальная художественная проза.
7. Есть действия и реакции, а не только объяснения.
8. Диалоги различаются по голосу.
9. Есть обычная жизнь вне основной загадки.
10. Есть отношения между персонажами.
11. Есть юмор там, где он органичен.
12. Есть физическая и сенсорная конкретика.
13. Мир раскрывается через сцену.
14. Тайна развивается постепенно.
15. Улики честны.
16. Нет внезапных решений.
17. Нет противоречий канону.
18. Глава заканчивается изменением, вопросом или новым направлением.
19. Текст перечитан как читатель, а не только как автор.
20. После QA только тогда выполняется GitHub commit.

Этот блок является последним шлюзом перед сохранением главы.
