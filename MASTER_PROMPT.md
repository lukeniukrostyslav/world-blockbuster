# WORLD BLOCKBUSTER — MASTER PROMPT

## Каноническая директива
Дата получения: 2026-09-22.

Проект: WORLD BLOCKBUSTER.
GitHub: https://github.com/lukeniukrostyslav/world-blockbuster

Это новый оригинальный коммерческий роман международного уровня. Нельзя обещать бестселлер. Цель — максимизировать качество, эмоциональную силу, читаемость, оригинальность, коммерческий и экранизационный потенциал.

### Жёсткий порядок
Исследование → литературный анализ → reader hook engine → несколько концепций → выбор концепции → тема → персонажи → мир → правила → тайна → архитектура → scene plan → literary bible → production → главы → полная редактура → continuity → fair play → emotional editing → commercial editing → language editing → word count → final QA → EPUB → publication package.

### Оригинальность
Пять загруженных книг являются исследовательскими материалами. Нельзя копировать текст, персонажей, миры, названия, уникальные сюжетные решения, характерные сцены, формулировки или узнаваемую манеру.

### Исследовательская база
Harry Potter and the Philosopher’s Stone; The Hobbit; Percy Jackson and the Lightning Thief; Coraline; The Graveyard Book.

### Проза
Полноценные литературные абзацы, естественный ритм, конкретные детали, физическое присутствие, атмосфера, внутренние реакции и действия. Систематический телеграфный стиль и постоянные абзацы из двух-трёх слов запрещены. Короткие абзацы допустимы только как осознанный инструмент.

### Сцена
PLACE / TIME / CHARACTERS / GOAL / OBSTACLE / ACTION / REACTION / CHANGE / NEW INFORMATION / EMOTIONAL CONSEQUENCE.

### Глава
Перед написанием — CHAPTER BRIEF.
После — DRAFT → LITERARY QA → CONTINUITY QA → MYSTERY QA → PARAGRAPH QA → WORD COUNT → GITHUB → VERIFY.

### GitHub
GitHub — центральное хранилище. Нельзя выдумывать commit SHA. После значимого блока необходимо сохранить, получить реальный SHA и проверить изменения.
