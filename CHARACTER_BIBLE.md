# B12 — CHARACTER BIBLE

Дата: 2026-09-22
Статус: B12 — 100%

## Принцип

Это литературная библия первой книги. Имена, возраст, голос, желания, страхи, секреты, отношения и арки здесь закреплены как рабочий канон.

Количество: **20 основных различимых персонажей**. Это не обязательная квота для каждой главы.

## 1. Главный герой — Илья Воронцов
Возраст: 16.
Роль: POV и центр эмоциональной арки.
Внешность: худощавый, тёмные волосы, внимательный взгляд; привычка носить блокнот.
Характер: наблюдательный, упрямый, заботливый, склонный превращать тревогу в планы.
Хочет: доказать, что исчезнувший из памяти человек существовал, затем понять механизм.
Боится: однажды обнаружить, что сам забыл близкого.
Слабость: принимает контроль за заботу.
Сильная сторона: замечает конкретные детали.
Секрет: несколько лет назад он уже пережил небольшой эпизод, который объяснял как обычную ошибку памяти.
Арка: контроль → расследование → вмешательство → цена → выбор настоящего.
Голос POV: конкретный, наблюдательный, эмоциональный без постоянной патетики; юмор возникает из ситуации и характера.

## 2. Эмоциональный якорь — Мира Левина
Возраст: 16.
Связь: близкий человек Ильи, отношения существуют до начала mystery.
Характер: самостоятельная, прямая, терпеть не может, когда за неё решают.
Хочет: сохранить нормальную жизнь и честность в отношениях.
Боится: стать для близкого человека проектом, который нужно «исправить».
Сильная сторона: видит эмоциональную правду ситуации.
Слабость: когда чувствует предательство, закрывается.
Секрет: она тоже хранит один старый предмет, связанный с забываемым человеком.
Арка: доверие → подозрение → конфликт → самостоятельный выбор → новая форма связи.

## 3. Партнёр расследования — Артём «Тёма» Климов
Возраст: 16.
Характер: быстрый ум, сухой юмор, любит проверять утверждения.
Хочет: найти объяснение, которое выдержит проверку.
Боится: оказаться бесполезным рядом с человеком, который видит больше.
Сильная сторона: логика и способность спорить с героем.
Слабость: иногда прячет страх за шуткой.
Секрет: в семье есть собственный случай противоречивой памяти.
Арка: скепсис → сотрудничество → конфликт из-за риска → самостоятельное действие → равноправный союз.

## 4. Человек, который помнит невозможное — Елена Рудина
Возраст: 42.
Профессия: реставратор бумажных архивов.
Характер: спокойная, внимательная, не любит быстрых выводов.
Хочет: сохранить свидетельства тех, чьи связи с людьми исчезают.
Боится: снова вмешаться и повторить старую ошибку.
Сильная сторона: терпение и знание архивных следов.
Слабость: скрытность.
Секрет: она знает о прежнем вмешательстве больше, чем говорит.
Арка: недоверие → проверка Ильи → частичное наставничество → признание прошлого → ответственность.

## 5. Человек, связанный с забываемым — Павел Серов
Возраст: 38.

Секрет: он намеренно отказался от одного способа восстановления, потому что уже видел его цену.
Функция: человеческое последствие mystery.

## 6. Представитель системы — Андрей Марков
Возраст: 45.
Профессия/маска: городской специалист по архивам и регистрации.
Характер: спокойный, убедительный, не угрожает без необходимости.
Хочет: удержать механизм в равновесии.
Боится: повторения городского сбоя, который он видел в прошлом.
Сильная сторона: системное мышление.
Слабость: считает допустимым принимать решения за других, если считает цену неизбежной.
Секрет: когда-то его собственное решение стало причиной чужой потери.
Арка: противостояние → аргументированное объяснение → раскрытие прошлого → столкновение с выбором Ильи.

## Голосовой принцип

Каждый персонаж должен быть различим не только именем:
- через длину и ритм реплик;
- через тип вопросов;
- через реакцию на страх;
- через характерный способ замечать детали;
- через действие вместо объяснения.

Нельзя давать всем персонажам одинаковый сарказм, одинаковую загадочность или одинаковую манеру говорить.
