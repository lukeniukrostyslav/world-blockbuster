# B19 — НАПИСАНИЕ РОМАНА: ПРОИЗВОДСТВЕННЫЙ ЖУРНАЛ

Дата: 2026-09-22
Статус: 3%

## Основание

Перед началом B19 повторно проверен загруженный EPUB Harry Potter and the Philosopher's Stone. Технически извлечено около 87,680 слов и 17 глав. Для первой главы WORLD BLOCKBUSTER использованы только общие проверенные механизмы: постепенное нарушение обычной жизни, физическая конкретность странности, маленькая улика, социальная реакция, семейная информация, постепенное повышение ставок и финальный вопрос, который толкает героя дальше.

Не копируются персонажи, имена, сцены, диалоги, сюжетная последовательность, мир, магическая система или авторская манера.

## Выполнено

### Глава 1 — «Карта, которой не должно быть»

Файл: `chapters/01_MAP_THAT_SHOULDNT_BE.md`

Целевой объём: около 2,400 слов.
Фактический объём текущей версии: 2,256 слов.

Функции главы:
- обычная жизнь Alex;
- его личная особенность — внимание к расстояниям и деталям;
- первая физическая странность — карта с отсутствующей дорогой;
- проверка странности в реальном пространстве;
- первый fair-play знак BH-04;
- Maya получает первый контакт с проблемой;
- семейная реакция показывает, что взрослым известно больше;
- письмо с обозначением Border House;
- новая карта и число 42;
- самостоятельное решение Alex двигаться дальше.

## Контроль B18

Проверено:
- полноценные абзацы;
- нет искусственного оформления каждой короткой фразы отдельной строкой;
- международные имена;
- сенсорные детали;
- причинно-следственная связь;
- первая улика существует до будущей разгадки;
- Alex не получает внезапной способности, не показанной заранее;
- Maya не сведена к функции помощника;
- нет копирования исходных произведений.

## Производственный принцип

Не растягивать главу искусственно ради цифры. Если сцена работает при меньшем объёме, качество важнее механического достижения числа. При необходимости глава может получить дополнительную редактуру в B22–B24.
