# B19.3 — ВВЕДЕНИЕ ПЕРСОНАЖЕЙ

Цель: читатель должен познакомиться с человеком, а не с анкетой.

Правила:
- показывать персонажа через действие, выбор, реакцию и речь;
- использовать несколько запоминающихся физических деталей, а не каталог внешности;
- голос персонажа должен отличаться от голоса других;
- отношения проявляются в разговоре и поведении;
- backstory давать только тогда, когда она становится релевантной;
- не вводить сразу весь большой состав;
- каждый новый персонаж получает функцию в сцене и отличительный признак.
